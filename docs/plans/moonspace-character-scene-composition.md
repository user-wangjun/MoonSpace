# MoonSpace 人物与场景构图文档

> 本文档用于记录《MoonSpace（月之隙）》Demo 阶段的人物与场景构图方案，作为后续像素美术资源、代码绘制精灵、地图摆放和镜头构图的设计依据。

## 一、整体美术方向

### 1.1 核心气质

- 类型：像素恐怖、规则怪谈、中国神话异化。
- 视角：俯视角 2D。
- 画面关键词：冷月白、青灰、深蓝黑、低饱和、局部血红。
- 恐怖表达：不依赖大面积血腥，而通过角色比例异常、面部模糊、循环动作失真、场景细节暗示规则。

### 1.2 像素规格

| 项目 | 规格 |
|---|---|
| 逻辑分辨率 | 480×270 |
| 推荐窗口 | 960×540，2 倍整数缩放 |
| 瓦片尺寸 | 16×16 |
| 主角/NPC | 16×24 或 16×20 |
| 大型物体 | 32×48 / 48×64 |
| 缩放方式 | 仅允许整数倍硬缩放 |

### 1.3 配色原则

| 类型 | 色彩倾向 | 用途 |
|---|---|---|
| 常态月宫 | 冷月白、青灰、深蓝黑 | 地面、宫墙、月光、角色轮廓 |
| 活体月桂 | 深绿、灰绿、暗木棕 | 月桂树、树根、树干人脸纹理 |
| 恐怖态 | 血红、暗红、青灰 | 违规反馈、树流血、死亡演出 |
| 人物高光 | 苍白肤色、月白边光 | 表现被月光照亮的异空间感 |

## 二、人物构图

## 2.1 玩家：凌霄宫使者伪装者

### 定位

玩家是误入月宫的现代人，但在月宫规则中必须伪装成“凌霄宫使者”。人物应表现出“不属于这里”的违和感，同时外观又要能被月宫短暂误认。

### 构图规格

| 项目 | 设计 |
|---|---|
| 推荐尺寸 | 16×24 |
| 朝向 | 上、下、左、右四方向 |
| 主体轮廓 | 瘦长、克制、略显僵硬 |
| 服装 | 深蓝长袍，带月白或暗金色衣缘 |
| 识别点 | 头部较小、长袍垂直线条、腰部细带 |

### 细节建议

- 头发使用深黑或蓝黑色，边缘加少量冷色高光。
- 面部不要过度写实，只保留眼部暗点和苍白面部高光。
- 长袍用竖向衣褶强化“使者”身份。
- 腰带可用暗金色作为小面积识别色。
- 行走动画不要太夸张，保持谨慎和压抑。

## 2.2 吴刚：永恒伐桂者

### 定位

吴刚是被规则困住的循环执行者。构图重点是“力量感”和“循环动作的异常”。他不是普通樵夫，而是一个已经被永恒惩罚扭曲的神话囚徒。

### 构图规格

| 项目 | 设计 |
|---|---|
| 推荐尺寸 | 16×24 |
| 动作 | 待伐、挥斧、砍中树干三帧循环 |
| 主体轮廓 | 上身宽、下身稳、动作僵硬 |
| 武器 | 大斧，斧刃应比身体轮廓更亮 |
| 识别点 | 肌肉纹理不自然、斧头角度略有偏差 |

### 细节建议

- 肤色不要太健康，应偏灰、偏暗。
- 胸肩位置加入不对称肌肉线条，暗示肉体在循环中扭曲。
- 斧刃使用月白或灰白高光，让砍伐动作清晰可读。
- 斧柄可用深木色，与月桂树树干区分。
- 第二次违规后，吴刚应从循环状态转为“面向玩家”的静止监视状态。

## 2.3 玉兔：蹲伏的类人生物

### 定位

玉兔不应画成可爱的兔子，而是“被称为玉兔的东西”。它应保留长耳、苍白、捣药等传统识别点，但身体结构必须让人不适。

### 构图规格

| 项目 | 设计 |
|---|---|
| 推荐尺寸 | 16×20 或 16×24 |
| 姿态 | 蹲伏、低头、手臂贴近药杵 |
| 轮廓 | 上半身小，下肢弯折异常 |
| 颜色 | 苍白、灰白、少量血红眼点 |
| 识别点 | 长耳、红眼、异常关节、捣药杵 |

### 细节建议

- 耳朵可以略长，但不要可爱化。
- 红眼只用 1～2 像素，避免变成夸张怪物。
- 关节线条可故意错位，形成“蹲得不自然”的感觉。
- 捣药动作建议两帧即可：药杵上抬、下压。
- 对话框“纯白无文字”的设定可以在 UI 中强化它的诡异感。

## 2.4 嫦娥：广寒宫中的模糊光团

### 定位

Demo 阶段嫦娥不直接交互，只作为远处广寒宫轮廓中的存在。她的构图重点不是角色细节，而是“看不清，但知道她在那里”。

### 构图规格

| 项目 | 设计 |
|---|---|
| 推荐尺寸 | 24×32，作为背景/远景虚影 |
| 表现方式 | 光团、人形剪影、长发和裙裾轮廓 |
| 色彩 | 月白、淡紫灰、冷白高光 |
| 识别点 | 模糊面部、飘逸长发、宽大衣裙 |

### 细节建议

- 面部不要清晰，只保留阴影或闪烁点。
- 用外层冷色暗边和内层月白高光表现光团。
- 可在后续动画中加入“掉帧”效果：某一帧出现不该存在的脸。
- 作为背景层时亮度不宜过高，避免抢走玩家视线。

## 2.5 月桂树：规则执行者

### 定位

月桂树不是背景物，而是整个 Demo 的最高压迫源。它必须像活体，又不能变成普通怪物。它应以静态构图制造被注视感。

### 构图规格

| 项目 | 设计 |
|---|---|
| 推荐尺寸 | 48×64 |
| 结构 | 大树冠、细长扭曲树干、外露根部 |
| 色彩 | 深绿树冠、暗木色树干、灰色人脸纹理 |
| 识别点 | 树干人脸、流血状态、根须延展 |

### 细节建议

- 树冠使用 2～3 层绿色表现体积。
- 树干纹理应构成若隐若现的人脸：眼、鼻、嘴不要太完整。
- 流血状态使用暗红从树干中段向下流，不要铺满全树。
- 违规 3 次死亡时，树根可从地面向玩家脚下延展。

## 三、场景构图

## 3.1 Demo 场景总体布局

Demo 场景分为两个主要区域：初始告示牌区域与月宫前院。玩家从告示牌区域读取规则后进入前院，逐步接触月桂树、吴刚、玉兔、月池与广寒宫远景。

### 推荐平面构图

```text
┌────────────────────────────────────────────┐
│                广寒宫远景（不可进入）       │
│        宫墙 / 冷月光 / 嫦娥模糊光团         │
│                                            │
│    吴刚        月桂树              玉兔     │
│   伐桂点      规则核心点          捣药台    │
│                                            │
│                  月池                      │
│                                            │
│         前院活动空间 / 规则触发区           │
│                                            │
│                 告示牌                     │
│                 初始点                     │
└────────────────────────────────────────────┘
```

### 构图原则

- 月桂树应放在视觉中心偏左或偏上位置，作为规则核心。
- 吴刚必须靠近月桂树，动作方向朝向树干。
- 玉兔与捣药台放在右侧，形成与吴刚的左右对照。
- 月池放在中下区域，方便玩家经过并触发倒影规则。
- 广寒宫只作为远景，不提供进入路径，形成目标诱导。

## 3.2 告示牌区域

### 作用

- 教学区，呈现 3 条基础规则。
- 给玩家建立“规则比战斗更重要”的预期。
- 从视觉上引导玩家进入月宫前院。

### 构图建议

- 告示牌放在玩家醒来的正前方。
- 周围地面较空，避免玩家误以为有其它交互目标。
- 告示牌应使用木质纹理，文字区域用冷白像素表现。
- 告示牌背后可暗示通往前院的路径。

## 3.3 月宫前院

### 作用

月宫前院是 Demo 的核心活动空间，承载所有规则验证、NPC 行为与世界扭曲反馈。

### 构图建议

| 元素 | 位置 | 作用 |
|---|---|---|
| 月桂树 | 中央偏上 | 规则核心、行礼检测、死亡来源 |
| 吴刚 | 月桂树左侧 | 循环伐桂，触发第 4 条环境规则线索 |
| 玉兔 | 右侧捣药台旁 | 对话、伪规则、对视规则 |
| 月池 | 中下区域 | 倒影规则、停留风险 |
| 广寒宫 | 最上方背景 | Demo 目标方向，不可进入 |
| 宫墙 | 顶部和侧边 | 限制边界，增强封闭感 |

## 3.4 月池

### 作用

月池承担“不可见使者倒影”的规则。它不是普通水面，而是会暴露身份的镜面。

### 构图建议

- 水面用深蓝外圈、浅蓝内圈、月白倒影高光。
- 波纹不能太密，避免看起来像装饰噪点。
- 玩家停留时可以让水面出现短暂人影或红色扰动。
- 月池周围地面可以略亮，引导玩家注意它。

## 3.5 广寒宫远景

### 作用

广寒宫是 Demo 终点方向，也是嫦娥存在的视觉暗示。它应宏大但不可抵达。

### 构图建议

- 位于画面顶部，作为背景层。
- 轮廓使用中式宫殿飞檐，但细节保持朦胧。
- 宫门区域可略亮，暗示 Demo 结束点。
- 嫦娥光团可置于门后或窗影中，若隐若现。

## 四、视觉层级与绘制顺序

### 4.1 绘制顺序

```text
地面瓦片
→ 宫墙 / 远景广寒宫
→ 场景物体（月桂树、月池、告示牌、捣药台）
→ NPC（吴刚、玉兔）
→ 玩家
→ 世界扭曲特效（根须、血月滤镜、像素闪烁）
→ UI（对话框、规则手册、死亡画面）
```

### 4.2 视觉优先级

| 优先级 | 元素 | 说明 |
|---|---|---|
| 最高 | 玩家、违规反馈、死亡根须 | 必须清晰可读 |
| 高 | 月桂树、吴刚、玉兔、月池 | 规则相关对象 |
| 中 | 告示牌、捣药台、宫门 | 交互或目标对象 |
| 低 | 地面纹理、远景宫墙 | 氛围背景，不能抢焦点 |

## 五、后续美术落地建议

### 5.1 第一阶段：静态精灵

- 完成玩家四方向站立图。
- 完成吴刚伐桂三帧。
- 完成玉兔蹲伏与捣药两帧。
- 完成月桂树常态与流血态。
- 完成告示牌、月池、捣药台、宫墙、广寒宫远景。

### 5.2 第二阶段：动画与恐怖反馈

- 玩家行走 4 帧循环。
- 吴刚砍树循环中加入微小角度偏差。
- 玉兔捣药时耳朵和药杵错帧。
- 月桂树轻微呼吸式膨胀。
- 违规后加入根须拖影、红色像素噪点、宫墙阴影变形。

### 5.3 第三阶段：规则叙事细节

- 月桂树砍击后短暂显现文字刻痕。
- 玉兔捣药台周围药渣排列成隐性规则线索。
- 月池倒影与玩家朝向联动。
- 广寒宫墙影在特定时刻拼出符号。

## 六、验收标准

- 玩家一眼能区分：主角、吴刚、玉兔、月桂树、月池。
- 玉兔不能显得可爱，必须保留类人生物的不适感。
- 月桂树必须表现出“活体规则执行者”的压迫感。
- 广寒宫必须是远景目标，不能抢走前院核心对象的视觉焦点。
- 所有核心物体在 2 倍整数缩放下边缘清晰，不使用平滑缩放。
- 恐怖感主要来自构图和规则暗示，而不是大量血腥表现。
