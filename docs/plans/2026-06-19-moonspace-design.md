# MoonSpace（月之隙）游戏设计文档

> 创建日期：2026-06-19 | 最终更新：2026-06-19 | Demo 原型阶段

---

## 一、项目概述

**MoonSpace** 是一款像素风恐怖解谜游戏，融合中国神话与规则怪谈玩法。玩家操控一个在家中玩游戏的年轻人，在血月之夜穿越进了名为 MoonSpace 的异空间——月宫。主角必须伪装成凌霄宫使者，在诡异的规则中求生，找到回归地球的路。

| 维度 | 说明 |
|------|------|
| 类型 | 像素恐怖 + 中国神话 + 规则怪谈 |
| 平台 | PC（Godot 导出），可扩展 Web |
| 视角 | 俯视角 2D |
| 玩法 | 解谜探索为主 + 规则型战斗辅助 |
| 技术栈 | Godot 4.x + GDScript |

## 二、世界观与叙事

### 2.1 开场流程

1. 主角在家中玩电脑，屏幕上显示刚下载的 MoonSpace 游戏
2. 窗外血月升起，红光透过窗户照到主角和电脑
3. 屏幕剧烈闪烁，画面扭曲，黑屏
4. 主角醒来，面前是一块木质告示牌
5. 读完规则，正式进入月宫

### 2.2 核心设定

- 主角**伪装成凌霄宫使者**来访月宫（凌霄宫已破碎，主角是冒牌货）
- 月宫有其规矩，作为使者必须遵守
- 违规就是露馅——月宫会逐渐认出你不是真使者
- 违规 3 次 → 身份败露 → 被杀死 → 化为月桂树养料
- **凌霄宫背景留白**，为后续作品做铺垫

### 2.3 月宫设定

月宫是月光照不到的夹缝空间，存在于阴阳之间。嫦娥、吴刚、玉兔被困于此，各自承受着永恒的诅咒。月桂树不是背景——它是活体，是规则的最高执行者，会吞噬违规者。

## 三、结局系统（完整版规划）

| 结局 | 类型 | 触发条件 |
|------|------|----------|
| **回归地球** | 真结局 | 破解嫦娥、吴刚、玉兔三者的规则链，不取代任何人，趁月之隙紊乱逃出 |
| **取代嫦娥** | 坏结局 | Boss 战后接手广寒宫，永世孤寂 |
| **取代吴刚** | 坏结局 | Boss 战后接过斧头，陷入永恒伐桂 |
| **取代玉兔** | 坏结局 | Boss 战后接过药杵，成为捣药囚徒 |
| **月桂养料** | 死亡结局 | 违规 3 次或战斗失败，被月桂树吞噬 |

**核心设计**：回归地球是唯一胜利，其余都是在月宫永世沉沦。月桂树树干上每张模糊的脸都是曾经的失败者。

## 四、规则系统（核心玩法）

### 4.1 规则分层

| 层级 | 说明 | 来源 |
|------|------|------|
| 告示牌规则 | 开局即知，刻在初始告示牌上 | 教学区 |
| 环境规则 | 藏于场景细节中，需要观察和推测 | 环境叙事 |
| 伪规则（陷阱） | NPC 或环境误导，遵守反而危险 | 角色交互 |

### 4.2 规则呈现方式：环境叙事

- 月桂树树干会随吴刚砍伐浮现短暂文字（仅持续数秒）
- 嫦娥望月时，广寒宫墙壁映出影子组成的符号
- 玉兔捣药台周围散落错位药渣，排列成某种规律
- **规则不是写在纸条上——是嵌在月宫本身里**

### 4.3 Demo 规则清单

**告示牌规则（开局显示）：**
1. 「凌霄来使，见树需稽首」——经过月桂树须面朝树停留 2 秒行礼
2. 「玉兔捣药时，不可与之对视」——玉兔捣药动画期间，主角面向它则违规
3. 「月池之水面，不可见使者的影子」——走过月池不能停下看倒影

**环境规则（需观察发现）：**
4. 月桂树闪光刻痕：「吴刚伐桂第五千下，树会流泪」——吴刚砍到特定次数时，月桂滴红汁，此时靠近安全、远离反而违规（逻辑反转）

**伪规则（危险诱导）：**
5. 玉兔对话中说：「广寒宫前，疾走以示敬意」——实际跑步触犯慢行的规矩

### 4.4 违规惩罚：世界扭曲（非 HP 制）

| 次数 | 后果 |
|------|------|
| 首次 | 地面出现月桂根须追随脚印（身后可见，回头就消失） |
| 二次 | 吴刚停下伐桂，转身盯着主角走（不再循环） |
| 三次 | 月桂树根从地底伸出 → 拖入地下 → 死亡（月桂养料） |

这不是"血条归零"，而是**月宫逐渐认出你**的过程：
- 第一次 → 怀疑
- 第二次 → 监视
- 第三次 → 判决

## 五、角色设计

### 5.1 嫦娥
- 形象：像素后面部为模糊光团，偶尔闪烁看到不该存在的脸，对话立绘随机"掉帧"
- 诅咒：永居广寒宫，不可离开半步
- Demo 原型中仅以广寒宫轮廓出现，不直接交互

### 5.2 吴刚
- 形象：肌肉纹理不正常扭动，斧头砍击完美循环但每斧角度有微妙偏差
- 诅咒：永远砍伐月桂树，随砍随合
- Demo 中在月桂树旁执行循环动画，违规 2 次后行为改变

### 5.3 玉兔
- 形象：不是兔子，是蹲伏的类人生物，关节角度不对，对话框纯白无文字但感觉在笑
- 诅咒：永远捣药，每日定量
- Demo 中可对话，会告知一条伪规则

### 5.4 月桂树
- 形象：活体，树干纹理在像素颗粒下如扭曲人脸
- 威胁机制：违规 3 次直接吞噬，树干上每张脸都是过往的失败者

## 六、战斗系统（Demo 不做）

| 类型 | 机制 |
|------|------|
| 普通遭遇 | 躲避/利用规则驱散，不正面战斗 |
| Boss 战 | 强制战斗，本质是规则解谜——用角色弱点规则破解 |

Boss 战后可选「帮其解脱」（推进回归结局）或「取而代之」（触发取代结局）。

## 七、Demo 原型范围

### 7.1 场景清单

1. **告示牌区域**：教学区，阅读 3 条基础规则
2. **月宫前院**：
   - 月桂树（吴刚伐桂循环）
   - 捣药台（玉兔）
   - 月池
   - 远处广寒宫轮廓（背景不可进入）

### 7.2 Demo 交互
- 自由走动，与 NPC 对话
- 环境里藏着第 4 条规则线索
- 玉兔对话给出第 5 条（伪规则）
- 违规触发世界扭曲 → 3 次后死亡
- Demo 结束于广寒宫门前

### 7.3 不做
- 战斗系统
- 完整多结局
- 嫦娥直接交互
- 音效

### 7.4 Demo 时长
预计 5-10 分钟

## 八、技术架构

### 8.1 技术选型

| 层 | 技术 |
|----|------|
| 游戏引擎 | Godot 4.x |
| 脚本语言 | GDScript |
| 渲染 | 2D 引擎，`texture_filter = Nearest`（硬像素） |

### 8.2 Godot 场景结构

```
scenes/
├── main.tscn                  # 入口场景
├── game_world.tscn            # 游戏世界
│   ├── tilemap_layer.tscn     # 地图瓦片层
│   ├── player.tscn            # 主角（CharacterBody2D）
│   ├── yutu.tscn              # 玉兔 NPC
│   ├── wugang.tscn            # 吴刚 NPC
│   └── laurel_tree.tscn       # 月桂树
├── ui/
│   ├── rule_panel.tscn        # 规则手册
│   ├── dialog_box.tscn        # 对话面板
│   └── screen_overlay.tscn    # 全屏特效
└── effects/
    ├── vine_creep.tscn        # 根须蔓延
    └── death_transition.tscn  # 死亡动画
```

### 8.3 核心脚本模块

```
scripts/
├── autoload/
│   ├── rule_engine.gd         # 规则引擎（全局单例）
│   ├── game_state.gd          # 游戏状态（违规次数、规则收集）
│   └── event_bus.gd           # 事件总线
├── player/
│   └── player_controller.gd   # 移动 + 碰撞
├── npc/
│   ├── npc_base.gd            # NPC 基类
│   ├── yutu_npc.gd            # 玉兔行为
│   └── wugang_npc.gd          # 吴刚行为
├── world/
│   ├── trigger_zone.gd        # 规则触发区域
│   └── world_distortion.gd    # 世界扭曲管理器
└── ui/
    ├── rule_panel_ui.gd
    └── dialog_ui.gd
```

```
project/
```

## 九、像素美术规格

- 角色精灵：16×16 / 32×32
- 游戏分辨率：480×270（16:9，整数倍缩放）
- 瓦片大小：16×16
- 字体：像素点阵中文字体
- 配色：暗色调为主，月光白 #C8D6E5、血月红 #C0392B、夜色黑 #1A1124
- 渲染：Nearest 滤镜，保留硬像素边缘
- 恐怖手法：角色面部模糊化、随机掉帧、像素闪烁、关节角度异常
